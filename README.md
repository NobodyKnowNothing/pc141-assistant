# PC141 Course Assistant

A question-answering assistant for students in **PC141 at Wilfrid Laurier University**. It answers the questions students email about: "When is my lab?", "What do I do if I miss it?", "Where do I submit my post-lab?", "What is the penalty for a first plagiarism offence?". Every statement in an answer cites the section it came from, and its quote is checked against that section.

- **Site:** <https://pc141-assistant.vercel.app> (Vercel, from `frontend/`)
- **API:** `https://wlu-rag-api.nobodyknownothing.workers.dev` (a Python Cloudflare Worker, from `backend/`)

## Layout

| Path | What it is |
|---|---|
| [`frontend/index.html`](frontend/index.html) | The whole site: a question box that calls the API. Vercel deploys it on every push to `vercel-deploy` ([`vercel.json`](vercel.json)). |
| [`backend/src/`](backend/src/) | The API, in Python with no dependencies. Only [`worker.py`](backend/src/worker.py) knows about Cloudflare. |
| [`backend/src/data/`](backend/src/data/) | The corpus: every citable section and its embedding. Generated by `scripts/build_corpus.py`; don't edit by hand. |
| [`backend/tests/`](backend/tests/) | Tests for retrieval, the prompt and the answer checks (`pytest`). |
| [`scripts/`](scripts/) | Building the corpus ([`sources.py`](scripts/sources.py) lists what goes in) and [`evaluate.py`](scripts/evaluate.py). |
| [`files/`](files/) | The PC141 PDFs: lab syllabus, lab manual, lab and tutorial announcements. |
| [`data/`](data/) | Evaluation questions, and the cached section labels (`chunk_labels.json`). |
| [`results/`](results/) | The latest evaluation runs. |

## How an answer is produced

```
question ─► retrieval.py ─────────────────────────► prompt.py ──► answer model ──► verify.py ──► answer
            5 PC141 sections + up to 3 Laurier       numbered       Gemma 4 26B      quotes,       claims marked
            sections (BM25 + embeddings + reranker)   sources        (JSON reply)     numbers,      verified or not
                                                                                      emails
```

1. **Sources.** The corpus has 598 sections: 63 from the PC141 PDFs and 535 from 34 official Laurier pages (the Academic Calendar's exam, grade, petition and date rules, the student pages on academic integrity, Gen AI, deferred exams, absences and Accessible Learning, and the university policies a student is likely to need: academic misconduct, accommodation, conduct, lab safety, severe weather, devices in class, student records). Each section keeps its citation: *PC141 Lab Syllabus (Fall 2026) > Requirements and Policies > Plagiarism Policy, p. 4*, or *Policy 12.2 … > 4.04 Penalties for Academic Misconduct* with a link that scrolls to it.
2. **Retrieval** ([`retrieval.py`](backend/src/retrieval.py)). PC141 and Laurier sections are each ranked by BM25 keyword search, by embedding similarity (`bge-small-en-v1.5`) and by a cross-encoder reranker (`bge-reranker-base`), and the rankings are fused. PC141 sections also carry a label (what the section is about and the questions it answers, written once by Gemma 4 and cached), so "marking scheme?" finds the lab manual's bare weight table and a reworded question still lands on the right section. A few student words are mapped to the documents' words (ChatGPT → "AI-based systems").
3. **Answer** ([`prompt.py`](backend/src/prompt.py)). The model must use only the numbered sources and returns JSON: claims from PC141 documents and claims from Laurier pages in separate lists, each with the source numbers and an exact quote. A university policy is never presented as a course rule.
4. **Checks** ([`verify.py`](backend/src/verify.py)). Claims citing no source are dropped. A claim whose quote isn't in the cited section, or that states a number, time or email the section doesn't contain, is marked unverified, and the page says so. If nothing is supported, the answer is "couldn't find an answer". The quote check proves the wording exists in the source; it can't catch every overstatement.

## API

`POST /` with `{"question": "What do I do if I miss my lab?"}` returns:

```json
{
  "status": "answered | partial | not_found",
  "pc141":   [{"text": "...", "quote": "...", "sources": [2], "verified": true}],
  "laurier": [{"text": "...", "quote": "...", "sources": [6], "verified": false, "issue": "..."}],
  "unverified": "what couldn't be answered, if anything",
  "sources": [{"n": 1, "id": "PC141labRules#7", "kind": "pc141", "title": "...", "section": "...", "pages": [2], "text": "...", "score": 0.93}]
}
```

Add `"retrieveOnly": true` to get only `sources` (no answer-model call). Browsers may call it only from `ALLOWED_ORIGIN` (the Vercel site, set in [`backend/wrangler.jsonc`](backend/wrangler.jsonc)) and `localhost:8000`. When the daily model allowance is used up it answers `429`, and the page asks students to try again later.

## Running it

Needs Node 22+ (for `wrangler`) and Python 3.12+.

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt   # Windows; .venv/bin/pip elsewhere
.venv/Scripts/python -m pytest backend                                  # tests, no network needed
cd backend && npx wrangler dev                                          # API on :8787 (calls Workers AI)
python -m http.server 8000 -d frontend                                  # the page; on localhost it calls :8787
cd backend && npx wrangler deploy                                       # deploy the API
```

The site deploys itself when `vercel-deploy` is pushed.

### Updating the documents

Edit [`scripts/sources.py`](scripts/sources.py) (or replace a PDF in `files/`), then:

```bash
.venv/Scripts/python scripts/build_corpus.py           # re-fetches the Laurier pages
.venv/Scripts/python -m pytest backend
cd backend && npx wrangler deploy
```

Run it at the start of each term too, so the Calendar dates and policies are current. Laurier pages are parsed by [`web_sections.py`](scripts/web_sections.py) and PDFs by [`pdf_sections.py`](scripts/pdf_sections.py). New or changed PC141 sections are labelled by Gemma 4 through the Cloudflare API ([`labels.py`](scripts/labels.py); it uses your `npx wrangler login`). Embeddings are computed on your machine with the same model the Worker uses for questions.

## Models and limits

All three models run on Workers AI's free allowance (10,000 neurons a day, shared by every model and user): `@cf/baai/bge-small-en-v1.5` to embed the question, `@cf/baai/bge-reranker-base` to rerank, and `@cf/google/gemma-4-26b-a4b-it` (thinking off) to write the answer. The answer is by far the most expensive call. There is no answer cache and no second provider: when the allowance runs out, the API returns 429 until it resets (normally 00:00 UTC).

### Moving to a local model server

[`models.py`](backend/src/models.py) defines the three calls the assistant makes: `embed`, `rerank` and `generate`. To run off Cloudflare, implement them for your server (for example an OpenAI-compatible endpoint for the answer model, and bge-small-en-v1.5 and bge-reranker-base run locally), raise `OutOfQuota` if it has a usage limit, and call `assistant.answer(question, Corpus("data"), your_models)` from any web framework. `retrieval.py`, `prompt.py` and `verify.py` don't change. Keep the embedding model the same as `scripts/build_corpus.py`'s, or rebuild the corpus with the new one.

## Evaluation

```bash
.venv/Scripts/python scripts/evaluate.py retrieval    # sources only: cheap
.venv/Scripts/python scripts/evaluate.py answers      # full answers: ~47 answer-model calls
```

[`data/web_eval.json`](data/web_eval.json) has 47 questions: 19 on the course documents, 4 admin questions, 3 on the marking scheme, 10 on the key student pages, 6 on other policies and 5 the sources can't answer. [`data/paraphrase_eval.json`](data/paraphrase_eval.json) has 101 rewordings of the course questions. Results are saved in `results/`.
